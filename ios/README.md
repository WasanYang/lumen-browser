# MiniBrowser สำหรับ iPhone (แผน)

ยังไม่ได้เริ่มเขียนโค้ด ไฟล์นี้เก็บแผนไว้ เพื่อเริ่มทำต่อบน Mac ได้ทันที

## เป้าหมาย (เรียงตามความสำคัญ)
1. **เล่น YouTube ต่อได้ตอนพับจอหรือสลับแอพ** และมีปุ่มเล่น/หยุดบนหน้าจอล็อก
2. **บล็อกโฆษณา** ทั้งแบนเนอร์บนหน้าเว็บและโฆษณาวิดีโอใน YouTube
3. **จำการล็อกอิน** หลังปิดแอพ

## สิ่งที่ต้องมี
| สิ่งที่ต้องมี | หมายเหตุ |
|---|---|
| Mac + Xcode | ใช้ build และติดตั้งลง iPhone |
| XcodeGen | `brew install xcodegen` แล้วสั่ง `xcodegen` ในโฟลเดอร์นี้ จะได้ไฟล์ `.xcodeproj` |
| Apple ID | แบบฟรี: แอพหมดอายุทุก 7 วัน · Apple Developer 99 USD/ปี: ไม่หมดอายุ |
| iPhone + สาย | เปิด Settings → Privacy & Security → Developer Mode |

## วิธีที่วางไว้
- **เล่นเบื้องหลัง:**
  - ฝั่ง iOS: ตั้ง `UIBackgroundModes: audio` และ `AVAudioSession` แบบ `.playback`
  - ฝั่ง YouTube: ใส่สคริปต์ที่บอก YouTube ว่าหน้าเว็บยังเปิดอยู่เสมอ (`document.hidden` = false, `visibilityState` = visible, ไม่ส่งเหตุการณ์ `visibilitychange`) และสั่งเล่นต่อถ้าโดนหยุดตอนสลับแอพ
  - Brave บน iPhone ใช้หลักการเดียวกัน ใช้เป็นตัวเทียบตอนทดสอบได้
- **บล็อกโฆษณา:**
  - แปลง `../shared/blocklist.txt` เป็นกฎบล็อกในตัวของ iOS (`WKContentRuleList`)
  - โฆษณาวิดีโอ YouTube ส่งมาจากเซิร์ฟเวอร์เดียวกับวิดีโอจริง จึงต้องใช้สคริปต์แทน: ลบข้อมูลโฆษณาออก หรือปิดเสียงและเร่ง 16 เท่าแบบบน Windows
  - iPhone ได้ YouTube เวอร์ชันมือถือ (`m.youtube.com`) ซึ่งหน้าเว็บต่างจากเดสก์ท็อป ต้องหาตัวเลือก (selector) ใหม่
- **การล็อกอิน:** ใช้ `WKWebsiteDataStore.default()` ซึ่งเก็บคุกกี้ไว้ถาวรอยู่แล้ว

## ความเสี่ยงที่ต้องลองบนเครื่องจริง
- iOS บางรุ่นอาจหยุด *วิดีโอ* ตอนพับจอ แม้เล่นเสียงเบื้องหลังได้
- Google อาจไม่ให้ล็อกอินในแอพที่ฝังหน้าเว็บ ลองตั้ง User-Agent เป็นของ Safari
- บน Windows การลบข้อมูลโฆษณาทำให้ YouTube หน่วงการเริ่มวิดีโอ 3–13 วินาที บน iPhone ต้องวัดใหม่
- การข้ามโฆษณาบน Windows ใช้การคลิกจริงผ่าน DevTools ซึ่ง iOS ไม่มี
- ใช้ส่วนตัวได้ แต่ส่งขึ้น App Store น่าจะไม่ผ่าน เพราะขัดกับเงื่อนไขของ YouTube

## ถ้าไม่มี Mac
build บน GitHub Actions (macOS runner) แบบไม่เซ็น ได้ไฟล์ `.ipa` แล้วติดตั้งจาก Windows ผ่านสายด้วย Sideloadly โดยใช้ Apple ID ของตัวเอง
ข้อเสีย: แก้แต่ละรอบช้า และดูข้างในหน้าเว็บตอนรันบน iPhone ไม่ได้ (เครื่องมือนั้นต้องใช้ Safari บน Mac)
