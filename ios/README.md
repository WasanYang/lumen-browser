# Lumen สำหรับ iPhone และ iPad (ต้นแบบ)

แอปเดียวใช้ได้ทั้ง iPhone และ iPad ไว้ฟังเพลงบน YouTube (Swift + UIKit + WKWebView)
บล็อกโฆษณาด้วยโค้ดชุดเดียวกับแอป Mac ([`../shared/LumenCore`](../shared/LumenCore))

## สิ่งที่ต้องมี
- Xcode (สคริปต์เรียกผ่าน `DEVELOPER_DIR` จึงไม่ต้องเปลี่ยน `xcode-select`) และ XcodeGen (`brew install xcodegen`)
- Apple ID ล็อกอินใน Xcode → Settings → Accounts (บัญชีฟรีก็ได้)
- iPhone/iPad: เปิด Developer Mode (Settings → Privacy & Security → Developer Mode) และเสียบสายกับ Mac

## Build และติดตั้ง
ทุกคำสั่งรันจากโฟลเดอร์ `ios`
```
./build.sh sim              # ติดตั้งและเปิดบน iPhone Simulator
./build.sh sim --selftest   # รันชุดทดสอบใน Simulator ผ่านหมดจะขึ้น ALL PASSED
./build.sh device           # ติดตั้งและเปิดบน iPhone/iPad ที่เสียบสายอยู่
```
`SIMULATOR="iPad Pro 11-inch (M5)" ./build.sh sim` ใช้ทดสอบบน iPad Simulator
ถ้าจับคู่ไว้หลายเครื่อง ระบุชื่อเครื่องได้: `DEVICE=iPad ./build.sh device` (เลือกเครื่องที่ชื่อมีคำว่า iPad)
สคริปต์รวมไฟล์ที่อยู่ที่อื่นใน repo (blocklist, uBO, ไอคอน) ไว้ใน `Generated/` แล้วสร้าง `Lumen.xcodeproj` จาก `project.yml` (ทั้งสองอย่างไม่ได้เก็บใน git)

**บัญชีฟรี**
- ติดตั้งครั้งแรกแล้วต้องกดเชื่อถือก่อน: Settings → General → VPN & Device Management → Apple Development → Trust
- เครื่องใหม่: เปิด Developer Mode แล้วรัน `DEVICE=<ชื่อเครื่อง> ./build.sh device` ครั้งแรก Xcode จะลงทะเบียนเครื่องให้เอง
- แอปเปิดได้ 7 วันหลังเซ็น จึงมี**ต่ออายุอัตโนมัติ** (`renew.sh`): Mac เช็คทุกวัน 7:30 แล้วติดตั้งใหม่ให้เครื่องที่ต่ออายุครั้งล่าสุดครบ 6 วัน
  ผ่าน Wi-Fi หรือสาย (การล็อกอินยังอยู่) สำเร็จจะเงียบ ไม่สำเร็จจะมีแจ้งเตือนบน Mac และลองใหม่วันถัดไป
  - เปิดใช้: `./install-renew.sh` · ปิด: `./install-renew.sh --remove` · สั่งต่ออายุตอนนี้: `./renew.sh`
  - log: `~/Library/Logs/Lumen/renew.log` · วันที่ต่ออายุล่าสุดของแต่ละเครื่อง: `~/Library/Logs/Lumen/renew-state`
  - Mac ต้องล็อกอินค้างไว้ (หลับได้ ถ้าหลับตอน 7:30 จะรันตอนตื่น) และมือถืออยู่ Wi-Fi เดียวกับ Mac
  - ถ้า Lumen เล่นเพลงอยู่ตอนต่ออายุ แอปจะถูกปิดเพื่อติดตั้งตัวใหม่

## ทำอะไรได้บ้าง
- เปิด YouTube เต็มจอ iPhone ได้เว็บมือถือ (`m.youtube.com`) iPad ได้เว็บเดสก์ท็อปแบบ Safari บน iPad
- แถบลอยแบบ Safari ด้านล่าง: ปุ่มย้อนกลับ ชื่อเว็บ และปุ่ม ⋯ (ไปข้างหน้า โหลดใหม่ หน้าแรก อัปเดต uBO
  และจำนวนโฆษณาที่หลุดมา) เลื่อนจอลงแล้วแถบย่อเหลือชื่อเว็บ เลื่อนขึ้นหรือแตะเพื่อกางกลับ
- ปุ่ม ⋯ มีจุดสีเขียวเมื่อมี uBO รุ่นใหม่ เลือกอัปเดตจากเมนู แล้วปัดปิดแอปและเปิดใหม่เพื่อเริ่มใช้
- ปัดจากขอบจอเพื่อย้อนกลับ ภาพซ้อนภาพ (Picture in Picture) และเต็มจอ
- **ฟังต่อตอนล็อกจอหรือสลับแอป**: iOS (WebKit) หยุดวิดีโอเองตอนแอปเข้าพื้นหลัง
  แอปจำว่ากำลังเล่นอยู่แล้วสั่งเล่นต่อทันที และหลอกหน้า YouTube ว่ายังเปิดดูอยู่
- จำการล็อกอิน และส่งตัวเองเป็น Safari เพื่อให้ล็อกอิน Google ได้
- ดูข้างในหน้าเว็บได้จาก Safari บน Mac → Develop → ชื่อเครื่อง → Lumen

## ต่างจาก Mac
- ไม่มีการกดปุ่มข้ามโฆษณาด้วยการแตะจริง (iOS ไม่มีวิธีส่งการแตะเข้าหน้าเว็บ) โฆษณาที่หลุด uBO มาจะถูกปิดเสียงและเร่ง 16 เท่า
- เว็บมือถือของ YouTube มีกฎ uBO น้อยกว่าเว็บเดสก์ท็อป (8 กับ 31 กฎ) ไม่มีกฎตัดเวลารอ 17 วินาที
- YouTube มือถือเปิดคลิปแบบปิดเสียงถ้ายังไม่ได้แตะ ต้องแตะเปิดเสียงเอง
- iOS เปิดแอปตัวเองใหม่ไม่ได้ หลังอัปเดต uBO ต้องปัดปิดแล้วเปิดเอง
