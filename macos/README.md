# Lumen สำหรับ Mac (ต้นแบบ)

แอปไว้ฟังเพลงบน YouTube อย่างเดียว เบาที่สุดเท่าที่ทำได้ ไม่ใส่เครื่องมืออื่น (Swift + AppKit + WKWebView)
ตอนนี้เป็นต้นแบบหน้าต่างเดียว ส่วนบล็อกโฆษณาตั้งใจเขียนให้ย้ายไปใช้กับแอป iPhone ได้ ([`../ios`](../ios))

## สิ่งที่ต้องมี
- macOS 14 ขึ้นไป
- Command Line Tools (`xcode-select --install`) ไม่ต้องใช้ Xcode เต็ม

## Build และรัน
ทุกคำสั่งรันจากโฟลเดอร์ `macos`
```
./build.sh                 # ได้ build/Lumen.app
open build/Lumen.app
./build.sh --install       # build แล้วติดตั้งทับ /Applications/Lumen.app (ต้องปิดแอปก่อน)
```
ติดตั้งใหม่หรืออัปเดตแล้วยังล็อกอินอยู่ เพราะข้อมูลล็อกอินเก็บใน `~/Library` ตาม bundle ID ไม่ได้อยู่ในตัวแอป
ไอคอนสร้างจาก [`../shared/Assets/logo.svg`](../shared/Assets/logo.svg) ทุกครั้งที่ build (`make-icon.swift`)
ทดสอบตัวเองใน WKWebView จริง (เปิดหน้าต่างทดสอบแป๊บเดียว ไม่แตะข้อมูลล็อกอิน):
```
build/Lumen.app/Contents/MacOS/Lumen --selftest
```
ผ่านทั้งหมดจะขึ้น `ALL PASSED` และจบด้วย exit 0 ตรวจ 5 อย่าง:
1. URL โฆษณาโหลดไม่ได้เมื่อเปิดตัวบล็อก แต่โหลดได้เมื่อปิด (แยกปัญหาเน็ตออกจากผลของตัวบล็อก) และ URL ปกติโหลดได้
2. CSS ซ่อนช่องโฆษณาบนหน้าเว็บ
3. สคริปต์ของ uBlock Origin Lite โหลดครบ และเอาข้อมูลโฆษณาออกจากข้อมูลของเครื่องเล่น YouTube (หน้าจำลอง)
4. ดาวน์โหลด uBO รุ่นล่าสุดจาก GitHub ลงโฟลเดอร์ชั่วคราวได้ครบ และเช็คซ้ำแล้วบอกว่าเป็นรุ่นล่าสุด (ต้องต่อเน็ต)
5. หน้า YouTube จำลองที่มีโฆษณาหลุดมา: ปิดเสียง เร่ง 16 เท่า แอปกดปุ่มข้ามด้วยคลิกจริง (`isTrusted`) แล้วคืนเสียงและความเร็ว
   ทดสอบทั้งตอนหน้าต่างอยู่ข้างหน้าและตอนซ่อนแอป

## บล็อกโฆษณาอย่างไร (`../shared/LumenCore`)
1. **บล็อก URL**: [`../shared/blocklist.txt`](../shared/blocklist.txt) แปลงเป็น `WKContentRuleList` ซึ่ง WebKit บล็อกเองก่อนส่งคำขอ
2. **สคริปต์ YouTube ของ uBlock Origin Lite**: ใช้ไฟล์ชุดเดียวกับที่ Windows ใส่เป็น extension
   (`ublock-filters` และ `ublock-experimental` จาก [`../windows/Extensions/uBOLite`](../windows/Extensions/uBOLite))
   ทำงานเฉพาะบน youtube.com เอาโฆษณาออกจากข้อมูลของเครื่องเล่นก่อน YouTube จะอ่าน โฆษณาส่วนใหญ่จึงไม่เริ่มเล่นเลย
3. **ซ่อนช่องโฆษณา** ด้วย CSS
4. **ตัวสำรอง**: ถ้ายังมีโฆษณาหลุดมา จะปิดเสียง เร่ง 16 เท่า และกดปุ่มข้ามให้
   ตัวนับที่มุมขวาบนคือจำนวนโฆษณาที่หลุดมาถึงข้อนี้

**อัปเดต uBO**: ปุ่ม **↻ uBO** มุมขวาบน
- Lumen เช็คกับ GitHub วันละครั้ง (ตอนเปิดแอป และทุกชั่วโมงระหว่างเปิดค้าง) ถ้ามีรุ่นใหม่ ปุ่มจะมี**จุดสีเขียว** แต่ยังไม่ดาวน์โหลดเอง
- กดปุ่มเมื่อพร้อม: ดาวน์โหลดแล้วถามว่าจะเปิด Lumen ใหม่ตอนนี้เลยไหม (รุ่นใหม่เริ่มใช้หลังเปิดใหม่) กดตอนไม่มีจุดก็ได้ จะเช็คทันที
- ชี้เมาส์ค้างที่ปุ่มเพื่อดูรุ่นที่ใช้อยู่และรุ่นใหม่ เมนู Lumen → อัปเดต uBlock Origin Lite… ทำเหมือนกดปุ่ม
- ดาวน์โหลดไฟล์ที่ build แล้วจากโฟลเดอร์ `chromium/` ของ [uBOL-home](https://github.com/uBlockOrigin/uBOL-home) ทีละไฟล์
  ไปไว้ใน `~/Library/Application Support/Lumen/uBOLite/<รุ่น>`
  ระหว่างรุ่นที่ติดมากับแอป (จาก `windows/Extensions/uBOLite` ตอน build) กับรุ่นที่ดาวน์โหลด รุ่นใหม่กว่าจะถูกใช้

## ทำอะไรได้อีก
- เปิด YouTube เป็นหน้าแรก จำการล็อกอินไว้หลังปิดแอป
- ป๊อปอัปที่ไม่ได้มาจากการคลิกลิงก์จะถูกทิ้ง
- ส่งตัวเองเป็น Safari (User-Agent) เพื่อให้ล็อกอิน Google ได้
- ดูข้างในหน้าเว็บได้ด้วย Safari → Develop → Lumen

| คีย์ | ทำอะไร |
|---|---|
| ⌘L | ไปที่แถบ URL (พิมพ์คำค้นได้เลย) |
| ⌘R | โหลดใหม่ |
| ⌘[ / ⌘] | ย้อนกลับ / ไปข้างหน้า |
| ⌃⌘F | เต็มจอ |

## ต่างจาก Windows
- ใช้แค่สคริปต์ YouTube ของ uBO ไม่ใช่ทั้ง extension (WKWebView ไม่รองรับ extension) จึงไม่มีรายการบล็อกทั้งเว็บของ uBO
- สคริปต์ของเราทำงานใน content world แยก สคริปต์ของ YouTube เห็น DOM เดียวกันแต่เรียกตัวสั่งคลิกจริงไม่ได้
- ยังไม่ได้ทำ `ForceH264` (ชิป Apple Silicon ถอดรหัส VP9 ด้วยฮาร์ดแวร์อยู่แล้ว)
- ยังไม่มีแท็บ และการพักแท็บ
