# MiniBrowser

Browser มินิมอลสำหรับ Windows (C# + WPF + WebView2) พร้อมตัวบล็อกโฆษณาในตัว

## สิ่งที่ต้องมี
- .NET 10 SDK: `winget install Microsoft.DotNet.SDK.10`
- WebView2 Runtime (มีใน Windows 11 อยู่แล้ว)

## รัน
```
dotnet run -c Release
```
ทำเป็นไฟล์ .exe ไฟล์เดียว:
```
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

## คีย์ลัด
| คีย์ | ทำอะไร |
|---|---|
| Ctrl+L | ไปที่แถบ URL (พิมพ์คำค้นได้เลย) |
| Ctrl+T / Ctrl+W | เปิด / ปิดแท็บ (คลิกกลางที่แท็บก็ปิดได้) |
| Ctrl+Tab, Ctrl+1..9 | สลับแท็บ |
| Alt+← / Alt+→ | ย้อนกลับ / ไปข้างหน้า |
| F11 | เต็มจอ |

## ตัวบล็อกโฆษณา (`AdBlock.cs`)
1. **บล็อกที่ต้นทาง**: แก้รายการได้ใน `blocklist.txt` (แก้แล้วเปิดโปรแกรมใหม่)
2. **ซ่อนช่องโฆษณา**: CSS ใน `PageScript`
3. **YouTube**: ถ้ามีโฆษณาวิดีโอ จะปิดเสียง เร่งเป็น 16 เท่า และกดปุ่มข้ามให้อัตโนมัติ

ถ้าไม่อยากเห็นโฆษณาแวบขึ้นมาเลย ให้ตั้ง `AdBlock.PruneYouTubeAds = true` เพื่อลบข้อมูลโฆษณาออกจากข้อมูลของเครื่องเล่น
แต่ YouTube จะจับได้และหน่วงการเริ่มวิดีโอ (วัดได้ช้าขึ้นราว 3–13 วินาที)

## uBlock Origin Lite
โหลดอัตโนมัติจากโฟลเดอร์ `Extensions\uBOLite` (โฟลเดอร์ย่อยใดๆ ใน `Extensions` ที่มี `manifest.json` จะถูกติดตั้งเป็น extension)
- **อัปเดต:** ดาวน์โหลดไฟล์ `uBOLite_<version>.edge.zip` รุ่นใหม่จาก https://github.com/uBlockOrigin/uBOL-home/releases
  แตกไฟล์ทับโฟลเดอร์ `Extensions\uBOLite` แล้ว build ใหม่ โปรแกรมจะติดตั้งให้เองเมื่อเห็นเวอร์ชันเปลี่ยน
- **ปิด:** ลบหรือย้ายโฟลเดอร์ `Extensions\uBOLite` ออก
- เมื่อใช้คู่กัน ระบบกดข้ามโฆษณาของเราจะเป็นตัวสำรอง ทำงานเฉพาะเมื่อมีโฆษณาหลุดมา

ถ้าการ์ดจอเก่าแล้ว YouTube กระตุก ให้ตั้ง `AdBlock.ForceH264 = true`

## ประหยัดทรัพยากร
- แท็บเบื้องหลังลดการใช้หน่วยความจำทันที และถูกพักหลังไม่ได้ใช้ 5 นาที (ยกเว้นแท็บที่กำลังเล่นเสียง)
- ป๊อปอัปที่ผู้ใช้ไม่ได้คลิกเปิดเองจะถูกทิ้ง
